The most useless superpower imaginable, in a single line, entered in the [Worst Superpower](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe) bounty on [make.fun](https://make.fun).

## The entry

> I can instantly know the exact weight of any cloud I see — in pounds, to the decimal, forever, whether I want to or not.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
The program checks the line first: it must be 1–140 characters, per the
bounty gate, and it refuses to write anything outside that range.
